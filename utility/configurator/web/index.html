Motores de Passo (Step Generators)

Regra de Hardware do Stepper Ninja: Para cada eixo (X, Y, Z, A...), os pinos de Step e Dir precisam ser GPIOs consecutivos no Pico (ex: GP0/GP1, GP2/GP3, GP4/GP5... ou Dir/Step invertidos: GP1/GP0, GP3/GP2).

Parâmetros de Pulso Globais

Recomendado: 2000ns a 5000ns para drivers comuns (DM542, TB6600, etc.)
Passos por milímetro ou grau (definido no HAL)

Encoders de Quadratura (Feedback / Spindle)

Cada encoder consome 2 pinos consecutivos no Pico (Pino base = Fase A, Pino base + 1 = Fase B).

Entradas Digitais (Fins de curso, Probe, E-Stop)

Nomes de Pinos no LinuxCNC HAL: Defina um nome amigável para cada entrada (ex: estop, probe, limit_x, arc_ok). O driver exportará os pinos HAL diretamente como stepper-ninja.0.<nome> e stepper-ninja.0.<nome>-not!

Saídas Digitais (Relés, Coolant, Enable)

Nomes de Pinos no LinuxCNC HAL: Dê um nome amigável para cada saída (ex: spindle, torch_on, coolant). O driver exportará como stepper-ninja.0.<nome>!
